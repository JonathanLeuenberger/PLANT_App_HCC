# PLANT_App_HCC

Plant-care class project. The current runnable contribution is Java plant search with Trefle, credited photos, offline guides and read-only plant profiles.

For the emulator demo, start `./server/start.sh`, open this folder in Android Studio and run **app**. The private Trefle token stays on the server.

See [search setup and team integration](docs/SEARCH_FEATURE.md), [private server setup](server/README.md) and [content credits](docs/SEARCH_THIRD_PARTY.md).
