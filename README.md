# PLANT_App_HCC

Plant-care class project. The current runnable contribution is Java plant search with Trefle, credited photos, offline guides and read-only plant profiles.

Open this folder in Android Studio and run **app**. Online search uses the shared HTTPS server at https://plant-app-hcc.onrender.com; teammates do not need an API token or local server. The first search may take about a minute while free hosting wakes up. Sixteen starter guides also work offline.

See [search setup and team integration](docs/SEARCH_FEATURE.md), [private server setup](server/README.md) and [content credits](docs/SEARCH_THIRD_PARTY.md).
